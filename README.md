# Anaya Martin Mbiyu - Portfolio

Static site: `index.html` + `media/`. No build step.

## Deploy on GitHub Pages
1. Create a new repo on github.com (e.g. `portfolio`), public.
2. Upload everything in this folder (`index.html`, `media/`, `.nojekyll`) to the repo root.
3. Repo > Settings > Pages > Source: "Deploy from a branch", Branch: `main`, folder `/ (root)` > Save.
4. After a minute your site is live at `https://<your-username>.github.io/portfolio/`.
   (Name the repo `<your-username>.github.io` to get `https://<your-username>.github.io/` instead.)
